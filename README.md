# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organize, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are saved in the browser using localStorage so that they remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work or Study
- View the date and time each note was created
- Delete individual notes
- Search notes in real time
- Case-insensitive searching
- Validate empty notes
- Limit notes to 200 characters
- Display the total number of notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive layout for smaller screens

## How to Run Locally

1. Clone or download the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with Live Server.
4. Use the application in your browser.

No additional dependencies or installations are required.
